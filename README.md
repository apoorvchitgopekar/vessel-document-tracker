# Vessel Document Tracking Dashboard

Live dashboard tracking shipping-document completion for inbound vessels to Mombasa.

- **Data source:** Google Sheet (fetched live in the browser on every page load, auto-refreshes every 10 minutes)
- **Hosting:** GitHub Pages — the page is static; all data comes from the sheet, so updating the sheet updates the dashboard with no redeploy needed.

The source Google Sheet must remain shared as "Anyone with the link – Viewer" for the dashboard to load data.
